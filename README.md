# BookStore

Многостраничный адаптивный сайт книжного интернет-магазина «Книжный Мир». Выполнен на HTML5 и CSS3.

## Страницы

- `index.html` — главная страница: первый экран с CSS-анимациями, преимущества магазина, подборка популярных книг, отзывы покупателей с формой добавления и блок контактов с формой обратной связи.
- `pages/catalog.html` — каталог книг с фильтрами по жанрам и цене, сортировкой, сеткой товаров и пагинацией.
- `pages/korzina.html` — страница корзины с подсчетом стоимости, вводом промокода и формой оформления заказа.
- `pages/bookview1.html` – `pages/bookview6.html` — карточки отдельных книг с подробным описанием, характеристиками и интерактивной галереей.

## Главные особенности

- Адаптивность: сайт корректно отображается на смартфонах, планшетах и мониторах (CSS Grid, Flexbox, медиа-запросы `@media`).
- Все интерактивные элементы сделаны на чистом CSS: мобильное гамбургер-меню, переключение ракурсов обложек в галерее книги, увеличение фото по клику (модальный просмотр).
- Плавные анимации баннера на `@keyframes` (парящие книги, бегущие волны).
- Кастомный шрифт Century Gothic и иконки FontAwesome.

## Структура проекта

```text
index.html             главная страница
styles.css             основные стили страниц
media/
  banners/             баннеры и фоновые изображения
  bookimages/          обложки книг
  fonts/               шрифт Century Gothic
  icons/               иконки интерфейса и соцсетей
pages/
  catalog.html         каталог книг
  korzina.html         корзина и оформление
  bookview1-6.html     детальные страницы книг
```

## Как открыть

Открыть файл `index.html` в любом браузере.
